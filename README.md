1 - So, what does this bad boy do?
Guess what? It does MATH!

For now, it does:
    - Addition
    - Subtraction
    - Multiplication
    - Division
    - Keeps waiting for your lazy ass until you leave
    - Prevents division by zero without getting bamboozled
    - Judges you if you choose an option that doesn't exist
    - Politely informs you that it can't read when you type letters instead of numbers (yknow, safety measures)

This was definitely a great first programming experience instead of just doing "Hello, World!", honestly. 
I learned some things like:
    - Variables and data
    - User input with da Scanner
    - if, else if and else (obviously)
    - while loops
    - Comparison and logical operators
    - try / catch
    - Basic exception handling
    - And more basic and obvious things, ofc

2 - To make it work, simply:
  Compile:
    javac Calculadora.java
  Then run:
    java Calculadora
  Then just do whatever you please.
